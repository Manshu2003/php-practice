# 🐘 PHP Practice & Job Post CRUD Project

Welcome to my **PHP Practice** repository! This repository documents my backend web development journey with PHP and MySQL—ranging from basic syntax and form handling to a complete **Job Post CRUD Application**.

---

## 📂 Repository Structure

* **`01_basie_Tution/`**: Core PHP fundamentals, variables, loops, arrays, and basic syntax exercises.
* **`php_Forms/`**: Handling `GET` and `POST` requests, form validation, and user input processing.
* **`Advanced_php/`**: Sessions, cookies, file handling, and intermediate-to-advanced PHP concepts.
* **`php_project/jobpost/`**: A full-stack **Job Post Management System** built with PHP, MySQL, and CSS featuring complete **CRUD** (Create, Read, Update, Delete) functionality (`index.php`, `home.php`, `display.php`, `update.php`, `delete.php`).

---

## 🛠️ Tech Stack

* **Backend:** PHP
* **Database:** MySQL (via phpMyAdmin)
* **Frontend:** HTML5, CSS3
* **Local Server:** XAMPP / Apache
